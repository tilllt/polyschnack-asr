# OpenSpec-Spezifikation

Die App ist retroaktiv in [OpenSpec-Format](https://openspec.dev/) spezifiziert:

- `openspec/project.md` — Überblick + External Systems
- `openspec/specs/*/spec.md` — 7 Capabilities mit Requirements/Scenarios
- `openspec/changes/*/proposal.md` — 5 Change-Proposals der Feature-Epochen

## Pflege

**Neue Features → neues Change-Proposal + Spec-Abschnitt aktualisieren**
(im gleichen Commit). So bleibt die Doku mit dem Code synchron und die
Architektur-Entscheidungen sind nachvollziehbar.
