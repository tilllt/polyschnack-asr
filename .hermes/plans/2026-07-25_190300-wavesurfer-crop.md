# WaveSurfer Audio Waveform + Crop Integration Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Replace the basic `<audio>` player with WaveSurfer.js — add waveform visualization, click-to-seek, and audio region cropping **before** sending to ASR.

**Architecture:** WaveSurfer.js (MIT, ~80 kB gzipped) renders waveform client-side via Web Audio API. A `RegionPlugin` lets users drag start/end handles on the waveform. The selected time range is sent as `start_sec` / `end_sec` query params when the user clicks "Transcribe Selection". The backend FFmpeg-trims the audio to that region before sending to the ASR service. Existing full-file playback is preserved.

**Tech Stack:** `wavesurfer.js@7` + `@wavesurfer/react` wrapper. Backend: `pydub` or `ffmpeg-python` for server-side trimming (ffmpeg already installed in webapp Dockerfile).

## Task 2: Create WaveformPlayer component

**Objective:** A standalone React component that wraps WaveSurfer. Replaces the current `<audio>` element in RecordingCard. Shows waveform + playback controls.

**Files:**
- Create: `webapp/frontend/src/components/WaveformPlayer.tsx`

**Step 1: Write WaveformPlayer**

```tsx
import { useEffect, useRef, useState } from "react";
import WaveSurfer from "wavesurfer.js";
import RegionsPlugin from "wavesurfer.js/dist/plugins/regions.js";

interface Props {
  audioUrl: string;
  onRegionChange?: (start: number, end: number) => void;
}

export function WaveformPlayer({ audioUrl, onRegionChange }: Props) {
  const containerRef = useRef<HTMLDivElement>(null);
  const wsRef = useRef<WaveSurfer | null>(null);
  const regionsRef = useRef<RegionsPlugin | null>(null);
  const [playing, setPlaying] = useState(false);

  useEffect(() => {
    if (!containerRef.current) return;
    const regions = RegionsPlugin.create();
    const ws = WaveSurfer.create({
      container: containerRef.current,
      waveColor: "rgba(91,140,255,0.3)",
      progressColor: "rgba(91,140,255,0.8)",
      cursorColor: "#3b82f6",
      cursorWidth: 1,
      barWidth: 2,
      barGap: 1,
      barRadius: 2,
      height: 80,
      plugins: [regions],
    });

    ws.load(audioUrl);
    ws.on("play", () => setPlaying(true));
    ws.on("pause", () => setPlaying(false));

    regions.on("region-updated", (r) => {
      onRegionChange?.(r.start, r.end);
    });

    wsRef.current = ws;
    regionsRef.current = regions;

    return () => { ws.destroy(); };
  }, [audioUrl]);

  const togglePlay = () => wsRef.current?.playPause();

  return (
    <div className="w-full">
      <div ref={containerRef} className="w-full" />
      <div className="flex items-center gap-3 mt-2">
        <button onClick={togglePlay} className="btn-ghost-sm text-[13px]">
          {playing ? "⏸" : "▶"}
        </button>
      </div>
    </div>
  );
}
```

## Task 5: New backend crop-transcribe endpoint

**Objective:** Add `POST /api/recordings/{rid}/transcribe-range` — accepts `start_sec` and `end_sec`, trims audio with ffmpeg, sends trimmed bytes to ASR, updates recording with new result in-place or creates a new segment recording.

**Files:**
- Create/Modify: `webapp/app/routers/recordings.py`
- Modify: `webapp/app/service.py`

**Step 1: Add helper to trim audio bytes with ffmpeg**

In `service.py`:

```python
import subprocess as sp
import tempfile

def _trim_audio(audio_bytes: bytes, start: float, end: float) -> bytes:
    """FFmpeg-based audio trimming. Returns WAV bytes."""
    with tempfile.NamedTemporaryFile(suffix=".in") as fin, \
         tempfile.NamedTemporaryFile(suffix=".wav") as fout:
        fin.write(audio_bytes)
        fin.flush()
        dur = end - start
        sp.run([
            "ffmpeg", "-y", "-i", fin.name,
            "-ss", str(start), "-t", str(dur),
            "-acodec", "pcm_s16le", "-ar", "16000", "-ac", "1",
            fout.name,
        ], capture_output=True, check=True)
        return fout.read()
```

**Step 2: Add endpoint**

In `recordings.py`:

```python
@router.post("/recordings/{rid}/transcribe-range")
def transcribe_range(
    rid: int,
    start_sec: float = Query(...),
    end_sec: float = Query(...),
    request: Request = None,
    background: BackgroundTasks = BackgroundTasks(),
    session: Session = Depends(get_session),
):
    """Crop audio to [start_sec, end_sec] and re-transcribe that segment."""
    rec = get_recording(session, rid)
    if rec is None:
        raise HTTPException(404)
    uid = _current_user(request)
    if uid is not None and rec.user_id != uid:
        raise HTTPException(403)
    audio_bytes = Path(rec.stored_path).read_bytes()
    trimmed = _trim_audio(audio_bytes, start_sec, end_sec)
    # Write trimmed bytes as a new file (or temp file)
    trimmed_path = Path(rec.stored_path).parent / f"{Path(rec.stored_path).stem}_crop.wav"
    trimmed_path.write_bytes(trimmed)
    # Create a new recording entry for the cropped segment
    new_rec = create_recording(
        session,
        original_name=f"{rec.original_name}_crop.wav",
        stored_path=str(trimmed_path),
        mime="audio/wav",
        size_bytes=len(trimmed),
        batch_id=rec.batch_id,
        enable_vad=rec.enable_vad,
        enable_diarize=rec.enable_diarize,
        user_id=uid,
    )
    background.add_task(process_recording, new_rec.id)
    return _recording_to_dict(new_rec)
```

```typescript
export async function transcribeRange(
  id: number,
  startSec: number,
  endSec: number,
): Promise<Recording> {
  const params = new URLSearchParams({ start_sec: String(startSec), end_sec: String(endSec) });
  const res = await fetch(`/api/recordings/${id}/transcribe-range?${params}`, { method: "POST" }).then(checkOk);
  return res.json() as Promise<Recording>;
}
```

## Verification

1. **Before upload:** Audio file selected → waveform renders → user can drag crop handles → "Transcribe Selection" sends only the cropped range
2. **After upload (existing recording):** Open a completed recording → waveform shows → drag crop handles → "Transcribe Selection" creates a new recording with the cropped region
3. **Full playback:** Click the waveform anywhere to seek. Play/pause button works.

---
## Risks & Tradeoffs

| Risk | Mitigation |
|------|------------|
| WaveSurfer 7 API may differ from v6 | Pin to v7.x — the API above is for v7 |
| FFmpeg subprocess per crop request | Crops are small (~seconds), subprocess is fast |
| Large WAV in memory for playback | WaveSurfer loads via URL (streaming). FFmpeg writes WAV to disk |
| No crop on pre-upload (before file is stored) | WaveSurfer needs a URL. Upload first, then crop. Or use blob URL (FileReader → ObjectURL) |
